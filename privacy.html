THE WEBSITE / DATA HANDLING

Privacy, in plain language.

This page describes the website and its developer-kit interest form. Firmware you choose to run on a watch has its own behaviour.

BrowsingThe interest listYour choicesContact

Browsing the site.

The website serves its images, fonts and scripts from the same site. It does not add analytics, advertising trackers, cookies or browser storage for tracking.

When deployed to GitHub Pages, GitHub processes hosting request information under its own privacy statement. Links to GitHub and other external websites take you to those services, where their own policies apply.

The developer-kit interest list.

When registration is available, the form asks for an email address, an interest in a PCB or developer kit, and agreement to receive availability updates. You can optionally provide a country and a short project description.

The information is used for Hacktor Watch availability updates and to understand interest in the planned hardware. Joining the list does not place an order or take a payment.

Form information is sent only when you submit the form to a configured registration service. The website does not save a copy in your browser or in the public source repository. If registration is closed, the form does not send information.

Before registration opens, the project team will identify its registration provider and privacy contact here.

Your choices.

You can browse the project without joining the interest list. Optional fields can be left empty. To ask about correcting or removing interest-list information, contact the project team using the contact details published below when registration opens.

Please avoid including sensitive personal information in the project-description field.

Privacy questions.

The interest list has not opened yet. A privacy contact will be published when registration becomes available.

For questions about the hardware or software itself, use the project repository.
