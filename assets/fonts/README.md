# Self-hosted Manrope variable font

Official Google Fonts delivery, original WOFF2 bytes. Normal style, weight range 200–800. Font family: **Manrope**.

Use both Latin and Latin-extended files so Romanian names retain their correct diacritics. Their exact unicode ranges are recorded in provenance.json; declare each subset as a separate face with the same family and weight range. No third-party font request is needed at runtime.

The original SIL Open Font License 1.1 is in OFL-Manrope.txt. Source URLs, sizes, and SHA-256 checksums are in provenance.json.
