A FEW THINGS TO KNOW

Good questions.

Is Hacktor a finished consumer smartwatch?+

Hacktor is an open wearable platform for development and experimentation. For PCB and developer-kit enquiries, contact the project team. Package contents and availability will be announced when they are defined.

Can I build one myself?+

The hardware, firmware and mechanical designs are published in the project repositories. Start with the design files and the instructions for your chosen firmware. Assembly requires appropriate electronics tools and experience.

Which firmware should I start with?+

Arduino is a practical route for rapid experiments. NuttX offers a POSIX-oriented environment, while Zephyr combines an RTOS, hardware description and configurable services. Explore the software section for the current examples and supported features.

Can the watch run local machine learning?+

A small wake-word detector has run on Hacktor Watch using TensorFlow Lite Micro. Model size, working memory, audio processing and listening time all affect what fits your application.

How can I ask about a PCB or developer kit?+

Write to contact@hacktorwatch.com and tell us what you’d like to build. An enquiry does not place an order or involve a payment.
